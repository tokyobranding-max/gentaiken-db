# 原体験DB(仮)

自分の体験や感情、価値観をアーカイブして、迷った時、感じた時に立ち戻る場所。その試作（プロトタイプ）です。

## 開き方

`index.html` をブラウザで開くだけで動きます。インストールやサーバーは要りません。

## できること

- **カード**：年齢・体験・感情・価値観の4行でできたカードに、原体験を入れる
- **線**：カードの行と行を線でつなぐ。太さが強さを表し、外した線も薄く残る
- **もしも**：「このまま続ける」「転職する」などのカードを足し、どれが自分の原体験に根ざしているかを比べる
- **未来の線**：原点の体験からいままでの年数を、同じだけ先へ延ばした未来の点と、その可能性の一覧
- **版**：変える前の地図を保存し、あとで比べる、元に戻す
- **地図の操作**：カードを引っぱって動かす、拡大・縮小する、左右の欄と地図の大きさを変える
- **表示の切り替え**：マップ、リスト（カードの一覧）、統計（感情タグの回数など）、設定
- **検索**：体験・感情・価値観の言葉でカードを探す
- **書き出し・読み込み**：カード、線、版のすべてをファイルにして持ち出す

## データの扱い

- 入力した内容は、開いた端末のブラウザの中（localStorage）だけに保存されます。どこにも送信しません。
- 別の端末やブラウザで使うときは、「書き出す・読み込む」でファイルにして移してください。
- 最初に入っているのは、架空の人のサンプルです。「空にして自分の原体験を入れる」で消せます。

## いまの制約

- 試作です。「続く長さの目安」は仮の基準（届いている価値観が半分以上なら「長い」）で、判定や予測ではありません。
- AIによる候補出し（価値観、未来の可能性）は、Claudeのアーティファクトとして開いたときだけ使えます。このファイルを単体で開いた場合は、手で書く形になります。
- スマホやタブレットでの指2本の拡大・縮小には対応していません。左下のボタンを使ってください。
